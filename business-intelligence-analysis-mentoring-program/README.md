### Study Plan

13-week roadmap designed to achieve Business Intelligence Analyst A2 readiness.

### Module 01 — Professional Assessment

Initial assessment identifying strengths and growth opportunities.

### Module 02 — Project Discovery

Discovery activities performed for a Sales Dashboard initiative.

### Module 03 — Requirements Engineering

Requirements gathering, stakeholder analysis, user stories, epics and use cases.

### Module 04 — Requirements in Data Projects

Business Intelligence specific requirements lifecycle, data requirements, governance considerations and traceability practices.

### Module 05 — Requirements Documentation

Requirements documentation standards and modeling techniques, including SRS, BRD, BRS, URS, data models, context diagrams, decision tables and data flow diagrams.

### Module 06 — Data Analysis & Data Profiling

Profiling of the Sales Dashboard datasets (`sales_transactions.csv` and `sales_targets.csv`). Covers business-level and technical-level profiling, data quality assessment across 6 DQ dimensions, gap analysis, and recommendations. Total revenue: $1.8M across 209 transactions. Quota attainment: 89.0%.

### Module 07 — Data Visualization & Dashboard Design

End-to-end Tableau dashboard build using the profiled sales data. Includes KPI card design, interactive filters, enterprise color palette, custom icon assets, and best practices for dashboard layout and stakeholder communication.
