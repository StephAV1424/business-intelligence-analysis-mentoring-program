# KPI Icon Assets

Custom PNG icons generated for the Sales Performance Dashboard KPI cards (96×96px, circle badge style).

| File | Color | Symbol | KPI |
|------|-------|--------|-----|
| `icon_revenue.png` | Blue `#1E40AF` | $ | Total Revenue |
| `icon_deals.png` | Green `#065F46` | # | Deals Closed |
| `icon_quota.png` | Purple `#4C1D95` | % | Quota Attainment |
| `icon_avgrep.png` | Orange `#D97706` | $ | Avg Revenue per Rep |
| `icon_trophy.png` | Light Blue | 🏆 | Top Performer |

Generated via Python using `cairosvg` (SVG → PNG conversion).
Used in Module 07 — Data Visualization & Dashboard Design.
